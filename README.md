# Transit

SNS(유튜브/넷플릭스/인스타)를 오래 쓴 순간, 지금 해야 할 일과 연결된 5~10분짜리 전환 활동을 띄워서
자연스럽게 할 일로 넘어가게 도와주는 크롬 확장 프로그램입니다.

## 설치 방법

1. 이 페이지 우측 상단의 **Code → Download ZIP** 버튼으로 다운로드
2. 압축 풀기
3. 크롬 주소창에 `chrome://extensions` 입력
4. 우측 상단 **개발자 모드** 켜기
5. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 푼 폴더(`extension`) 선택
6. 설치된 Transit 카드에서 **확장 프로그램 옵션** 클릭

## 사용 전 준비

- [console.anthropic.com](https://console.anthropic.com)에서 자기 계정으로 API 키 발급 필요 (`sk-ant-...`)
- 옵션 페이지 열면 첫 실행 시 자동으로 튜토리얼이 뜹니다 — 그대로 따라하면 됨
- **API 사용량 비용은 각자 발급받은 키 기준으로 본인 부담입니다.**

## 주의

- 지금은 개인/지인 배포용 프로토타입이라 크롬 웹스토어에 정식 등록된 게 아니라서,
  브라우저를 새로 설치하거나 확장을 지웠다 다시 깔면 이 폴더를 다시 로드해야 합니다.
- Windows에서 로그인할 때마다 자동으로 뜨게 하고 싶으면 시작프로그램(`shell:startup`)에
  `chrome.exe --app=chrome-extension://<확장ID>/options.html` 바로가기를 만들면 됩니다.
