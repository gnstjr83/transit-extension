# Transit

SNS(유튜브/넷플릭스/인스타)를 오래 쓴 순간, 지금 해야 할 일과 연결된 5~10분짜리 전환 활동을 띄워서
자연스럽게 할 일로 넘어가게 도와주는 크롬 확장 프로그램입니다.
개인 최적화를 목표로 할 일 목록, 트리거 시간, 창 크기 등 대부분의 설정값을 조정할 수 있고, Transit만의 개성을 가지는 개인 최적화 노트북 캘린더를 지향합니다.

## 설치 방법

1. 받은 `transit-extension.zip` 압축 풀기
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 푼 폴더 선택
5. 설치된 Transit 카드에서 **확장 프로그램 옵션** 클릭

## 사용 전 준비

- [console.anthropic.com](https://console.anthropic.com)에서 자기 계정으로 API 키 발급 필요 (`sk-ant-...`)
- 옵션 페이지 열면 첫 실행 시 자동으로 튜토리얼이 뜹니다 — 그대로 따라하면 됨
- **API 사용량 비용은 각자 발급받은 키 기준으로 본인 부담입니다.**

## 사용법

- 확장 프로그램 옵션 카드를 열어 자신의 일정, 트리거, 감시 사이트를 설정하고 감시 사이트를 이용하시면 됩니다.
- 일정에는 제목, 기간, 내용이 있습니다. 내용은 구체적으로 기입하여 본인에게 맞는 구체적인 문제유형을 유도할 수 있습니다.
- 일정 10분 전부터 트리거 조건에 따라, 클로드 API를 통해 일정과 관련된 읽을거리 질문, 미니퀴즈, 사고미션, 실행미션 + 다음 행동 오버레이가 제시됩니다. (일정이 없으면 트리거 X)
- 새로운 영상 재생 시, 일시정지 후 재생 시 번거로운 토스트 알림이 쿨타임 없이 제시됩니다.
- 본인 해상도에 맞게 축소 옵션 픽셀 조절 가능합니다. (확대는 화면비율고정)
      
## 개인화

- Windows에서 로그인할 때마다 캘린더가 자동으로 뜨게 하고 싶으면 시작프로그램(`shell:startup`)에
  `chrome.exe --app=chrome-extension://<확장ID>/options.html` 바로가기를 만들면 됩니다.
- 본인의 크롬 계정에 Transit을 로드하고 사용하면, 다른 기기에서 본인의 크롬 계정에 Transit을 로드하고 동기화시킬 수 있습니다.  

## 주의

- 지금은 개인/지인 배포용 프로토타입이라 크롬 웹스토어에 정식 등록된 게 아니라서,
  브라우저를 새로 설치하거나 확장을 지웠다 다시 깔면 이 폴더를 다시 로드해야 합니다.
