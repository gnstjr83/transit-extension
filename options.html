오늘 할 일을 알려주세요

SNS를 오래 쓰는 순간, 이 일들로 넘어가는 다리를 만들어줄게요.

시작하는 법

  1. console.anthropic.com에서 API 키 발급 (sk-ant-로 시작)
  2. 아래 "Anthropic API 키 설정" 펼쳐서 키 붙여넣고 저장
  3. "할 일 추가"에 오늘 할 일과 주제 입력 (주제는 구체적일수록 좋아요)
  4. 이 창은 닫아도 됨 — 유튜브/넷플릭스/인스타를 오래 보면 자동으로 전환 활동이 떠요
  5. 활동 끝나면 "25분 집중 시작" → 다 되면 "시작했나요?" 알림에 답하면 성공률이 쌓여요
